# 위고비 펜 기기 사용법: FlexTouch 펜 상세 가이드

위고비는 노보 노디스크가 개발한 FlexTouch® 자동주사 펜으로 제공됩니다. 올바른 사용법을 숙지하면 안전하고 효과적으로 약물을 투여할 수 있습니다.

## FlexTouch 펜이란?

FlexTouch는 미리 채워진(pre-filled) 일회용 자동주사 펜입니다. 별도의 약물 충전이나 복잡한 조작 없이 버튼 하나로 약물을 주입할 수 있도록 설계되어 있습니다.

### 펜 구성 요소
- **펜 캡** — 사용 전 펜 팁 보호
- **용량 윈도우** — 남은 약물 확인창
- **주사 버튼** — 약물 투여 시 누르는 버튼
- **주사 팁 뚜껑** — 니들(바늘) 보호 커버
- **바늘(니들)** — 별도 구매, 사용 후 교체

## 사용 전 준비

### 필요 물품
- 위고비 FlexTouch 펜 (처방받은 용량)
- 새 주사 바늘 (4mm 32G 또는 처방에 따른 규격)
- 알코올 솜
- 날카로운 물체 전용 폐기 용기(샤프컨테이너)

### 사용 전 확인 사항
1. 펜 라벨의 약물명과 용량이 처방전과 일치하는지 확인
2. 유효기간(EXP) 확인 — 만료된 약물 사용 금지
3. 약물 외관 확인 — 무색 또는 옅은 황색, 투명해야 함 (흐리거나 입자가 보이면 사용 금지)
4. 냉장 보관 후 꺼낸 경우 상온에서 30분 이상 대기

## 주사 부위 선택

위고비는 피하주사(subcutaneous injection)로 투여합니다. 권장 주사 부위는 다음과 같습니다.

### 권장 부위
- **복부** — 배꼽 주위 5cm를 제외한 복부 피하지방 부위 (가장 흔히 사용)
- **허벅지 앞쪽** — 좌우 교대 사용
- **상완 뒤쪽** — 팔 뒤쪽 피하지방 부위

### 주사 부위 로테이션
같은 부위에 반복 주사하면 지방 이상증(lipodystrophy)이 생길 수 있습니다. 매주 주사 부위를 바꾸어 사용하는 것을 권장합니다.

## 단계별 주사 방법

### 1단계: 손 씻기
비누와 물로 손을 깨끗이 씻습니다.

### 2단계: 펜 캡 제거
펜에서 큰 펜 캡을 돌려서 제거합니다.

### 3단계: 바늘 부착
새 바늘을 펜 팁에 수직으로 맞추고 시계 방향으로 꽉 돌려 고정합니다. 이후 바늘 보호 캡(외부 캡, 내부 캡)을 순서대로 제거합니다. 내부 캡은 나중에 바늘 제거 시 필요하므로 보관합니다.

### 4단계: 공기 제거 확인 (Flow Check)
- 용량 선택기를 돌려 2 단위로 맞춥니다.
- 펜을 위로 들고 주사 버튼을 누릅니다.
- 바늘 끝에서 약물이 한 방울 이상 나오면 정상입니다.
- 약물이 나오지 않으면 바늘을 교체하고 반복합니다.

### 5단계: 용량 선택
용량 선택기를 돌려 처방받은 용량을 맞춥니다. 위고비의 용량은 0.25mg, 0.5mg, 1mg, 1.7mg, 2.4mg 단계가 있으며, 처방전에 기재된 용량을 사용합니다.

### 6단계: 주사 부위 소독
알코올 솜으로 주사 부위를 닦고 완전히 마를 때까지 기다립니다.

### 7단계: 피부 집기 (선택)
복부 피하지방이 적은 경우 피부를 가볍게 집어 올릴 수 있습니다.

### 8단계: 주사 시행
바늘을 피부에 90도 각도로 삽입하고 주사 버튼을 끝까지 누릅니다. 버튼을 누른 채로 **6초 이상 유지**합니다. 이는 전체 용량이 투여되도록 하기 위함입니다.

### 9단계: 바늘 제거 및 폐기
피부에서 펜을 뺀 후, 내부 캡을 이용해 바늘을 덮고 제거합니다. 사용한 바늘은 즉시 샤프컨테이너에 폐기합니다. **재사용하지 않습니다.**

## 보관 방법

### 사용 전
- 냉장 보관: 2~8°C (냉동 금지)
- 빛 차단하여 보관

### 사용 시작 후
- 상온 보관 가능: 최대 28일, 30°C 이하
- 냉장 또는 상온 중 선택하여 보관 가능
- 28일 경과 후 남은 약물은 폐기

## 자주 하는 실수와 주의사항

- **같은 바늘 재사용 금지** — 바늘이 무뎌져 통증 증가, 감염 위험 상승
- **주사 버튼을 6초 미만 누름** — 전체 용량이 투여되지 않을 수 있음
- **펜 흔들기 금지** — 인슐린과 달리 세마글루타이드 펜은 흔들 필요 없음
- **동결 펜 사용 금지** — 냉동된 약물은 폐기해야 함

## 언제 의료진에게 문의해야 하는가?

- 주사 부위에 발적, 붓기, 통증이 지속될 때
- 약물 외관이 불투명하거나 입자가 보일 때
- 용량 선택기가 정상적으로 작동하지 않을 때
- 주사 후 전신 반응(두드러기, 호흡 곤란 등)이 나타날 때

처음 사용하는 경우에는 의료진 또는 약사에게 실제 사용 시범을 요청하는 것이 좋습니다.
