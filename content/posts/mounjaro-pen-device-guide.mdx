# 마운자로 KwikPen 사용법 완전 가이드

마운자로(성분명: 티르제파타이드)는 일라이 릴리(Eli Lilly)가 개발한 GIP/GLP-1 이중 작용제로, KwikPen® 자동주사기 형태로 제공됩니다. 올바른 사용법을 숙지하면 안전하고 효과적인 자가주사가 가능합니다.

## KwikPen 특징

마운자로 KwikPen은 위고비의 FlexTouch와 유사하지만 몇 가지 차이점이 있습니다.

- **미리 채워진(pre-filled) 1회용 자동주사기** — 용량 선택 불필요, 1펜=1회 용량
- **각 펜은 단일 용량으로 제조** (2.5mg, 5mg, 7.5mg, 10mg, 12.5mg, 15mg 각각 별도 펜)
- **바늘 포함 여부:** 지역에 따라 바늘 포함 또는 별도 구매
- **싱글 다이얼 없음:** 용량을 선택하는 다이얼이 없어 조작이 간단

## 마운자로 용량별 펜 색상

| 용량 | 펜 색상(표준) |
|------|-------------|
| 2.5mg | 회색 |
| 5mg | 노란색 |
| 7.5mg | 주황색 |
| 10mg | 파란색 |
| 12.5mg | 분홍색 |
| 15mg | 자주색 |

처방 시 용량과 펜 색상을 교차 확인합니다.

## 사용 전 준비

### 필요 물품
- 처방받은 용량의 마운자로 KwikPen
- 주사 바늘 (KwikPen 전용 또는 호환 사이즈: 4mm 32G 권장)
- 알코올 솜
- 날카로운 물체 전용 폐기 용기

### 사용 전 확인 사항
1. 펜 라벨의 용량과 유효기간 확인
2. 약물 외관 확인: 무색 또는 황색을 띤 투명한 액체여야 함 (혼탁하거나 입자가 보이면 사용 금지)
3. 냉장 보관 후 꺼낸 경우 15~30분 상온 방치 후 사용

## 단계별 주사 방법

### 1단계: 손 씻기
비누와 물로 손을 30초 이상 씻습니다.

### 2단계: 펜 캡 제거
KwikPen의 회색 또는 컬러 베이스 캡을 제거합니다. 이때 약물 창(window)을 통해 약물을 육안으로 확인합니다.

### 3단계: 바늘 부착
새 바늘을 펜에 수직으로 맞추고 시계 방향으로 꽉 조입니다. 이후 바늘의 외부 캡과 내부 캡을 순서대로 제거합니다. 내부 캡은 보관합니다.

### 4단계: 안전 핀 제거 (Flow Check)
일부 KwikPen 모델의 경우 첫 사용 시 안전 핀(safety pin)을 제거해야 합니다. 제조사 지침서를 참조합니다.

### 5단계: 주사 준비 확인 (Prime)
펜을 위로 들고 주사 버튼을 가볍게 눌러 바늘 끝에 약물 한 방울이 나오는지 확인합니다. 이 단계는 공기를 제거하고 약물이 정상적으로 흐르는지 확인하는 절차입니다.

### 6단계: 주사 부위 선택 및 소독
주사 가능 부위는 다음과 같습니다.
- **복부** (배꼽 주위 5cm 제외)
- **허벅지 앞쪽**
- **상완 뒤쪽**

알코올 솜으로 주사 부위를 닦고 자연 건조시킵니다.

### 7단계: 주사 시행
바늘을 피부에 90도 각도로 삽입합니다. 주사 버튼을 천천히 끝까지 누르고 **최소 10초간 유지**합니다. 이는 전체 용량이 투여되도록 하기 위함입니다. 약물이 완전히 투여되면 클릭음이 나는 경우도 있습니다.

### 8단계: 바늘 제거 및 폐기
피부에서 펜을 뺀 후, 내부 캡을 이용해 바늘을 제거하고 즉시 샤프컨테이너에 폐기합니다. 사용한 바늘은 **절대 재사용하지 않습니다**.

### 9단계: 펜 폐기
마운자로 KwikPen은 1회용입니다. 바늘 제거 후 나머지 약물이 남아있어도 재사용하지 않습니다.

## 주사 부위 순환

매주 주사 부위를 교대합니다. 같은 부위에 계속 주사하면 지방 이상증이 생길 수 있습니다. 예를 들어, 1주차 오른쪽 복부 → 2주차 왼쪽 복부 → 3주차 오른쪽 허벅지 순으로 순환합니다.

## 보관 방법

### 사용 전 보관
- **냉장 보관:** 2~8°C (냉동 금지)
- 빛을 피해 보관

### 사용 후 또는 상온 보관
- 개봉 후 상온(30°C 이하) 보관 시 최대 **21일** 이내 사용
- 21일 경과 후 남은 약물이 있어도 폐기

## KwikPen과 FlexTouch 비교

| 항목 | 마운자로 KwikPen | 위고비 FlexTouch |
|------|-----------------|-----------------|
| 용량 선택 | 필요 없음 (1펜=1용량) | 필요 (다이얼 조절) |
| 주사 유지 시간 | 10초 | 6초 |
| 상온 보관 | 21일 | 28일 |
| 바늘 포함 | 지역마다 다름 | 별도 구매 필요 |

## 자주 하는 실수

- **주사 버튼을 10초 미만 누름** — 전체 용량 미투여 가능
- **냉동된 펜 사용** — 냉동 시 폐기 필수
- **혼탁한 약물 사용** — 반드시 외관 확인
- **같은 바늘 재사용** — 감염 및 통증 위험

처음 사용하는 경우, 처방 의사 또는 약사에게 직접 시범을 보여달라고 요청하는 것이 좋습니다.
