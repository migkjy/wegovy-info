# GLP-1 처방 병원 선택 체크리스트: 좋은 비만 클리닉 고르는 법

GLP-1 비만 치료제(위고비, 삭센다, 마운자로)를 처방받기 위해서는 적합한 의료기관을 선택하는 것이 중요합니다. 단순히 약을 받는 것을 넘어, 지속적인 모니터링과 생활습관 관리를 함께 지원하는 의료기관을 선택해야 안전하고 효과적인 치료가 가능합니다.

## 왜 병원 선택이 중요한가?

GLP-1 치료는 단순히 약을 처방받는 것 이상의 의료 행위입니다:

- **개인화된 처방**: 개인의 건강 상태, 동반 질환, 복용 약물에 따른 적합한 약제·용량 선택이 필요합니다
- **부작용 모니터링**: 오심, 구토, 췌장염 등 부작용 발생 시 신속한 대응이 필요합니다
- **정기 검사**: 혈당, 간기능, 신기능 등 주기적 혈액 검사가 권고됩니다
- **생활습관 상담**: 약물 치료와 함께 식이, 운동 조정이 치료 효과를 높입니다

## 병원 기본 자격 확인

**의사 면허 및 전문성**:
- [ ] 의사 면허를 보유한 의료인이 직접 진료하는가?
- [ ] 내과, 가정의학과, 또는 비만 관련 전문의가 진료하는가?
- [ ] 비만 치료 경험이 충분한가?

**의료기관 등록 여부**:
- [ ] 건강보험심사평가원에 등록된 의료기관인가?
- [ ] 비대면 진료 서비스의 경우 의료법 규정을 준수하는가?

## 진료 내용 체크리스트

**초진 진료**:
- [ ] 상세한 병력 청취(과거 질환, 현재 복용 약물, 가족력 등)를 하는가?
- [ ] BMI, 허리둘레, 혈압 등 기본 신체 계측을 하는가?
- [ ] 혈액 검사(혈당, HbA1c, 지질, 간기능, 신기능, 갑상선) 등 기본 검사를 권고하는가?
- [ ] GLP-1 처방의 적응증(BMI ≥ 25 + 동반 질환, 또는 BMI ≥ 30 이상)을 정확히 평가하는가?
- [ ] 금기 사항(갑상선 수질암 개인/가족력, 췌장염 과거력 등)을 확인하는가?

**처방 및 용량 조절**:
- [ ] 저용량에서 시작하여 단계적으로 증량하는 표준 용량 조절을 따르는가?
- [ ] 부작용 발생 시 용량 조절 방법을 안내하는가?
- [ ] 다른 복용 약물과의 상호작용을 검토하는가?

**교육 및 안내**:
- [ ] 주사 방법(자가 주사 기술)을 충분히 교육하는가?
- [ ] 보관 방법(냉장 보관 등)을 안내하는가?
- [ ] 주요 부작용과 대처 방법을 설명하는가?
- [ ] 응급 상황 시 연락 방법을 안내하는가?

**추적 관리**:
- [ ] 정기 재진 일정(1~3개월 간격)을 제시하는가?
- [ ] 추적 혈액 검사를 권고하는가?
- [ ] 체중, 혈압, 체성분 변화를 추적하는가?
- [ ] 부작용 발생 시 대응 체계가 있는가?

## 생활습관 지원 체크리스트

- [ ] 식이 상담 또는 영양사 연계 서비스를 제공하는가?
- [ ] 운동 처방 또는 지침을 제공하는가?
- [ ] 행동 변화 지원 프로그램이 있는가?
- [ ] 치료 목표(체중 감소 목표)를 함께 설정하는가?

## 비용 투명성 체크리스트

- [ ] 약제비, 진료비, 검사비를 사전에 명확히 안내하는가?
- [ ] 숨겨진 추가 비용이 없는가?
- [ ] 패키지 상품의 경우 포함 내용이 명확한가?
- [ ] 건강보험 급여 해당 여부(2형 당뇨 등)를 확인하고 안내하는가?

## 주의해야 할 신호 (Red Flags)

다음과 같은 의료기관은 주의가 필요합니다:

**즉시 경계해야 할 신호**:
- 의사 진료 없이 처방전을 발행하는 경우
- 검사 없이 최대 용량부터 시작을 권유하는 경우
- 처방전 없이 약을 직접 판매하는 경우 (불법)
- SNS, 온라인 쇼핑몰에서 GLP-1 약제를 직접 구매하도록 유도하는 경우

**주의가 필요한 신호**:
- 초진 시 2~3분의 매우 짧은 진료만 이루어지는 경우
- 부작용이나 금기 사항에 대한 설명이 없는 경우
- 과장된 체중 감소 효과를 보장하는 경우
- 추적 관리(재진, 검사)를 권유하지 않는 경우

## 비만 전문의 vs 일반 내과/가정의학과

**비만 전문의(또는 비만 클리닉)**:
- 비만 치료에 특화된 전문 지식
- 체성분 검사, 대사 검사 등 더 상세한 평가 가능
- 식이·운동 전문 상담 연계 가능
- 상대적으로 진료비가 높을 수 있음

**일반 내과/가정의학과**:
- GLP-1 처방 자격 있음
- 동반 질환(당뇨, 고혈압 등) 통합 관리에 유리
- 진료비 상대적으로 저렴
- 비만 전문 프로그램 지원이 적을 수 있음

## 비대면 진료 선택 시 추가 확인

- [ ] 의사가 화상/전화로 직접 진료하는가? (챗봇, AI 처방 아닌지 확인)
- [ ] 처방전이 약국으로 전송되는 공식 전자 처방 시스템을 사용하는가?
- [ ] 초진 가능 여부를 확인하는가? (2026년 기준 초진은 조건부 허용)
- [ ] 응급 상황 시 대면 의료기관 안내가 되는가?

## 결론

좋은 GLP-1 처방 병원은 단순히 약을 처방하는 것을 넘어, 안전한 치료를 위한 사전 평가, 지속적 모니터링, 생활습관 지원을 제공하는 의료기관입니다. 이 체크리스트를 활용하여 의료기관을 꼼꼼히 평가하고, 불법 경로나 무자격 의료행위는 절대 이용하지 마시기 바랍니다. 치료 결정은 담당 의사와의 충분한 상담을 통해 이루어져야 합니다.
